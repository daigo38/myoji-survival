# 苗字サバイバル

全国の名字ランキング上位1000姓を1万分の1に縮めた8,447人が画面の中を歩き回り、ぶつかるたびに五分五分でどちらかの苗字にそろっていくシミュレーションです。

**デモ：https://myoji-survival.pages.dev/**

## ルール

- 初期人数は、名字由来netの全国ランキング上位1000位の「およその人数」に0.0001をかけて四捨五入した値です。1位の佐藤（約179.8万人）は180人、1000位の紺野（約1.77万人）は2人で、合計8,447人になります。
- 各人は向きを少しずつ変えながら同じ速さで歩きます。
- 苗字の違う2人がぶつかると、50%ずつの確率でどちらかの苗字にそろいます。
- 苗字の最後の1人が変わると、その苗字は消えます。消えた場所には波紋が出ます。

これは数理モデルでいう「ボーター・モデル（中立浮動）」です。どの苗字にも有利不利がないため、最後に1つだけ残る確率はその苗字の初期人数に比例します。いちばん多い佐藤でも約2.1%（180 / 8,447）です。

## 画面

- **フィールド**：苗字ごとに色分けした点が動きます。点にマウスを重ねると苗字が見られ、クリックするとその苗字を追跡できます。
- **勢力ランキング**：上位12姓の人数とシェアです。苗字をクリックすると追跡でき、もう一度クリックすると解除します。
- **グラフ**：残っている苗字の数、現在の上位6姓のシェア推移、順位と人数（両対数）の3つです。
- **できごと**：苗字が消えたときと首位が入れ替わったときの記録です。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `public/index.html` | ページの骨組み |
| `public/style.css` | スタイル（ライト・ダーク両対応） |
| `public/app.js` | シミュレーションと描画 |
| `public/surnames.js` | 苗字と初期人数のデータ（生成物） |
| `scripts/fetch_surnames.py` | 名字由来netからデータを取り直して `surnames.js` を作るスクリプト |

ビルド工程はなく、`public/` をそのまま静的ファイルとして配信します。

## ローカルで動かす

```bash
bun run dev
```

http://127.0.0.1:8000/ を開きます。Python 3 の簡易サーバーを使っているので、Bun がなければ `python3 -m http.server 8000 --directory public` でも同じです。

## データを取り直す

```bash
bun run fetch-data
```

## デプロイ

Cloudflare Pages（プロジェクト名 `myoji-survival`）に配信しています。

```bash
bun install
bun run deploy
```

## データ出典

苗字と人数は [名字由来net 全国名字ランキング](https://myoji-yurai.net/prefectureRanking.htm) の「およその人数」（2026年9月30日取得）をもとにしています。
